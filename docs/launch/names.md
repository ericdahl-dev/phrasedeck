# Product name shortlist

For a phrasedeck product: buttons on a phone that type saved prompts into the focused window on
your computer, mostly for AI coding agents. "phrasedeck" itself is taken on the App Store. Names
with Claude, Anthropic, Stream Deck or "deck" were left out, to stay clear of Elgato.

Checked 2026-10-25. Nothing was bought or registered.

- **Domains:** each registry's RDAP server (Verisign for .com, Google Registry for .app and .dev).
  "Free" means the registry has no record, so the domain wasn't registered at that moment.
- **App Store:** the iTunes Search API, US store, for any app whose name contains the candidate
  (ignoring spaces and case).
- **Collisions:** one web search per name, for products and obvious trademarks. This was not a
  USPTO search.

| Name | App Store clash | Domains free | Notes |
|---|---|---|---|
| **Nudgekeys** | none | .com .app .dev | No product by that name. "Nudge" is a common app word (reminders, a Mac update tool), but nothing near this product. |
| **LGTMpad** | none | .com .app .dev | No product. "LGTM" is common developer slang, so it reads right to engineers, but it's hard to protect as a trademark and means nothing to anyone else. |
| **Agentclicker** | none | .com .app .dev | No product. Kortix's open-source `agent-click` (desktop automation for agents) and the "Agent.Click" prototype are close in spelling. |
| **Nudgeclick** | none | .com .app .dev | No product. Clear, but the meaning of "nudge" in it is weaker than in Nudgekeys. |
| **LGTMkeys** | none | .com .app .dev | Same as LGTMpad. |
| **Thumbkeys** | none | .com .app .dev | Thumb-Key, an open-source Android keyboard, plus older "Thumb Keyboard" apps. A near collision in the same category (keyboards). |
| **Nudgepad** | none | .app .dev | .com taken. No product found. |
| **Thumbprompt** | none | .app .dev | .com taken. No product found. |
| **Promptremote** | "PromptRemote" exists | .app .dev | .com taken. Exact App Store clash. |
| **KeyCue** | none | .app .dev | .com taken. KeyCue is an established Mac keyboard-shortcut app from Ergonis. A real clash, so not recommended. |

The names checked and dropped for App Store or domain collisions were Promptpad, Tapprompt,
Promptkeys, Agentpad, Cuepad, Promptboard, Typetap, Promptdock, Agentremote, Quickcue and Tapsay.

## Top 3

1. **Nudgekeys:** all three domains free, no clash anywhere, and it says what the app does: nudge
   your agents with keys.
2. **Agentclicker:** all three domains free, and it's plain about what it does (a clicker for
   agents). Its spelling is close to Kortix's `agent-click`.
3. **LGTMpad:** all three domains free, memorable to developers. The jargon limits who it's for
   and makes it weak as a trademark.

## Before choosing

- Search USPTO (and EUIPO, if it might sell there) for the chosen name in classes 9 and 42.
- Recheck that the domains are free just before registering them; these results are a snapshot.
- The registry has no record of `phrasedeck.app` or `phrasedeck.dev` (RDAP 404 on 2026-10-25),
  though the brief said they were registered. Worth checking if the name matters later.
